# V5 实施决定

原 V5 策略原文及开发 Prompt 在工程根目录原样保留；这里记录冲突处理，不改原文。

1. 更换工具不消除旧价格数据消费史。V4 final 已消费，V5 没有证据支持重新命名干净终测；只在原 DEV 做开发/年度验证，final 拒绝执行，G4 为 INCONCLUSIVE_DATA。
2. `(1-m)/D` 仅是研究仓位上限。美国绝对美元保证金、历史变更和触发细节未全核实；20%初始名义保证金及其50%维持比例只是 SCENARIO_ONLY，不保证某杠杆生存。
3. Kraken 现货、境外真实资金费率、真实美国永续分层；现货加境外费率仍为 SCENARIO_ONLY，不合成冒充美国成交/标记价格。缺费率不填零以声称完整永续表现。
4. 日 OHLC 不辨先后；冻结保守路径：开盘/已到时点资金结算→不利端→有利端→收盘。同段止损与强平都可能发生时先按强平处理，并另报路径敏感性。真实日内数据足够时另立更细版本，不事后挑有利顺序。
5. 套利主计划28天，30天仅敏感性。双腿完整往返、再平衡、划转、资金/基差成本均计入净收益门。限价不承诺成交，默认不计任何限价成交红利；吃单成本门通过才成交，可以零交易。
6. 美国现金资金调整采用 America/Chicago 15:00，DST自动转换；官方当前页面未确认文档中的三次计提时点，不能将19/03/11时写成已核实事实。境外每小时数据按其原机制计提，代理现金时点另标情景。
7. 25%为缩放参数；合并后重算协方差实现波动、虚拟总暴露、物理净仓、钱包初始/维持保证金。不把未用预算重新分配。现货浮盈不可抵永续保证金。
8. 现有V4冻结文件不修改。V5独立命名空间和入口，账务引擎是V5唯一主账本；Freqtrade仅对可比子集独立校核，禁止拼取两引擎最好结果。
9. 图节点固定8个具名现货研究节点，实际上市前及缺数据时mask。它不是完整历史美国市场名单；以今天名单选择上下文仍有存续/选择限制，金融结果限探索，只有BTC/ETH可交易。
10. SIDGTN五期限核心、真实因子和图分支必须跑通。情绪真实历史不够则 BLOCKED_DATA，其dataset/模型/优化/预测接口和fallback照常实现；合成梯度测试不算金融验证。动态融合先接线测试，但只在冻结增量门通过后训练比较。
11. 远程训练使用现有会话/已授权通道；不重建服务，不改安全设置。权限或工具确实不支持时保留作业包和单条启动命令，继续本地独立工作；不得把本地训练写成4090训练。

所有参数是研究假设，不是实盘授权。原文关于开户/实盘的路线不在本轮执行范围。
