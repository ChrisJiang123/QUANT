# V5 离线账务与 SIDGTN 接线

本实现只输出研究事件，不含下单适配器。主账本位于 `src/quant_platform/v5/book.py`，日级事件顺序位于 `engine.py`。`replay.py` 只执行真实有完整价格和费率区间的共同样本。真实美国资料、境外费率、现货价格和假设保证金分别保存，不混成美国永续历史。

物理净仓执行收费；趋势、套利、短周期持有独立虚拟仓。内部对冲不虚构交易所成交，但虚拟收益与净仓收益、资金计提必须守恒。现货模拟钱包和衍生品模拟钱包隔离，内部划转在途期间不能充当保证金；这里只是模拟账户。固定按张费包含在综合 bps 中，剩余摩擦进入成交价，不能再次从收益扣除。

资金事件按原始区间的时间加权持仓计提，按 Chicago15点转现金；夏令时由时区库计算。历史4h到1h切换通过原始区间覆盖检查，不能以日分组27h误判后补零。早年反向合约费率仅是融资代理，执行价格仍是现货开盘情景；历史单位依原始结算节奏推定，未升格为官方历史美元现金事实。

主路径为开盘、费率现金时线、不利极值、有利极值、收盘。日 OHLC 不揭示真实先后；同根穿越强平与止损时先处理强平。路径敏感性单独运行。硬回撤锁定不自动恢复。维护/停牌事件禁止普通再平衡，仍保留风险与结算。真实两小时健康监控不能由日线回测证明。

模型路径：固定数据快照→60根价格、8主因子、8辅助值和mask、8节点各8特征及因果相关图、7日情绪序列与mask→批次→价格Conv/Transformer、因子门控、辅助分支、图注意力→多模态静态权重→五期限头→归一化pinball/BCE/波动Huber/q05尾部pinball→AdamW→checkpoint→权重/缩放器→预测及信号导出。所有训练段缩放器与固定节点ID随权重保存。

core使用价格和主因子；factor增加真实可用辅助因子；graph在factor基础上增加图。basis、历史事件、新闻不足时严格mask，绝不将假零当真实中性。情绪适配器和缺失回退有测试；没有365日可证明可见性的新闻历史，金融实验BLOCKED_DATA。今日固定8个上下文节点不代表完整历史可投资市场，存在预选幸存者局限；每节点的实际首根和缺失单独mask，只交易BTC/ETH。

训练五种子11/22/33/44/55，2022/23/24年度WF与仅DEV拟合的最终推理模型，共60次拟合。28日purge、embargo以及内部180日校准，训练锚点间隔7日；这不能把重叠样本变成完全独立。温度只拟合内部purged校准段。动态Cross-Attention有可执行实现与梯度/回退测试，但只有预注册新增分支增量门通过才允许进一步研究；运行状态以validation.json为准。

新V5权重不兼容旧14/28日模型。旧权重预测先只读复现，旧tail Huber与新q05 pinball明确区分。四格替换在同一V5账户时序和成本下重新回放；旧收盘标签仍保留探索标记。DEV金融指标不能清洗已经消费的终测。

每次回放保存逐笔成交、事件哈希链、每日权益、分仓归因、方向归因、费用、资金、风险事件及可恢复状态。最后一根不强平，年度换折不重建钱包。Freqtrade仅对零融资一倍现货可比夹具对账；无法表达Kraken美国合约规格的部分不伪装成Freqtrade支持。
